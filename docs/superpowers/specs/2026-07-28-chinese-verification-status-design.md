# 中文验收状态展示设计

## 目标

将桌面端 Web 中面向用户的验收任务状态统一显示为中文，避免 `failed`、`building` 等内部英文状态码直接出现。

## 范围

- 覆盖“我的报告”列表与报告详情页。
- 仅改前端展示文案；数据库、Supabase RPC、API 响应和 Worker 状态值保持不变。
- 不改变状态轮询、重新验收、导出、权限或每日额度规则。

## 设计

在 `apps/web/src/features/jobs/` 建立单一状态映射函数，由报告列表和报告详情共同调用。

| 内部状态 | 用户看到的中文 |
| --- | --- |
| `queued` | 等待处理 |
| `preparing` | 正在准备项目 |
| `building` | 正在构建 |
| `running` | 正在启动 |
| `testing` | 正在检查 |
| `reporting` | 正在生成报告 |
| `completed` | 验收完成 |
| `failed` | 验收失败 |
| `timed_out` | 验收超时 |
| 未识别值 | 状态更新中 |

页面不再额外显示英文状态码。错误分类（如 `PROJECT_COMMAND_FAILED:PNPM_INSTALL:REGISTRY`）仍作为失败原因展示，不被状态翻译函数改写。

## 验收与测试

1. 映射函数为全部已知状态返回上表中文；未知值返回“状态更新中”。
2. 报告列表显示中文状态，不显示内部英文状态值。
3. 报告详情显示中文状态，不显示内部英文状态值。
4. 运行 Web 单元测试、类型检查、Lint 和差异检查。

## 边界

本次不新增移动端布局、状态字段、翻译库或后端接口，也不改变 Worker 执行逻辑。
